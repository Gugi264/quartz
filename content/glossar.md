# Index
Ein Index setzt sich aus mehreren Wertpapieren zusammen. Der Index bildet somit die Werteentwicklung der Gruppe ab. 
Der Index ist somit eine Art Barometer.

Ein Index kann über verschiedenste Dinge abgebildet werden, z.b.: einer Region, einer Branche oder die stärksten Unternehmen.

# Thesaurierung

Der Begriff ist aus dem Griechischen abgeleitet, "thesauros" kann mit "Schatzhaus" übersetzt werden, und steht für das Einbehalten von Gewinnen. Organisationen schütten also die erwirtschafteten Überschüsse nicht aus, sondern arbeiten weiter mit ihnen.

Im Fall von ETF's werden die Gewinne reinvestiert.
