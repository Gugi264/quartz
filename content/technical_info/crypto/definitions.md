Definitions needed for cryptography

## Entity Autentication / Identifcation
Verify the identity of a communication endpoint (device, user) based on
possession of some cryptographic identifier (password, key, ...)

## Message Authentication

### Authenticity
Verify the source of the message

### Integrity
Verify that the message has not been modified while in transit


## Hash
A cryptographic hash function $$H$$ maps a message ***M*** (a bitstring) of arbitrary length to a 
*t*-bit tag ***T*** that serves as a fingerprint/checksum for ***M***.
